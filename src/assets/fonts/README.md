# Navigation font

The `noto-sans-sc-rail-*.woff2` files are subsets of the Noto Sans SC variable
font embedded in the supplied v7 standalone prototype. They contain only
the Chinese glyphs used by the seven navigation labels, preserving the
prototype's lettering without downloading fonts at runtime.

The CSS family alias `AIMyChats Rail` is scoped to the navigation rail. The rest
of the application continues to use its existing typography.
