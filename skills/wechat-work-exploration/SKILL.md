# WeChat Work Exploration

用于用户要求“从聊天记录探索项目”“找相关群聊”“整理 timeline”“分析项目重点”时。

## 前置条件

- 桌面应用「AIMyChats」正在运行。
- `wxq` 已通过「Agent 集成 → 工具接入」页的提示词安装（来源 `/agent/wxq`）；若不可用，停止并让用户重新复制提示词。

## 标准流程

1. `wxq policy`——确认账号与白名单范围。
2. `wxq search --keyword 项目名 --groups-only`——按项目名、客户名、人员名和关键术语定位候选会话。输出会给出 `扫描 / 跳过 / 命中` 计数与每条命中的上下文片段。
3. `wxq messages --chat USERNAME --limit 100`——对命中的白名单会话按时间翻页取原文证据（`--before TS --before-id ID` 继续向前，两个值都会打印出来）。
4. `wxq digest --chat A --chat B --since ... --until ...`——获取确定性待办、决定、问题、风险、数据和时间线素材。
5. 结果按“证据原文 → 规则抽取 → Agent 分析”分层输出，并标注日期、会话和发言人。

## 约束

- 搜索结果受白名单和服务端上限约束（`--max-sessions` 最大 200），必须说明扫描数、跳过数和截断信息。
- 不把“关键词命中”表述成项目事实；结论需要原文核对。
- 不把规则整理称为 AI 总结，也不虚构未出现在消息中的决定、负责人或截止时间。
- 相关群聊只能从 `wxq search` 的白名单命中结果中发现；需要用户扩大范围时，提示其在「聊天白名单」页添加会话。
- 需要结构化处理时可加 `--json`，字段与服务端 MCP 工具返回一致；不要自行解析人类可读输出做二次统计。
